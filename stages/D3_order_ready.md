## Context
User will not do a pre-build actuator test; everything must be design-complete and checked on paper, then he orders everything once and builds on his Bambu A1. Design = hybrid: J1 STS3250 servo; J2/J3 printed 40:1 cycloidal actuators with Tarot TL2955 4008 330KV + B-G431B-ESC1 (CAN) + AS5600, each with a torsion balance spring (Springmasters 471671); J4/J5/J6/gripper STS3215 except J4 = STS3250; carrier PCB v1.3 (`pcb13/` on branch `pcb-v13`); firmware on `arm-fw2`; CAD on `arm-cad3`. Read `cad3/STATUS-cad3.md`, `cad3/BOM_delta.md`, `cad3/PRINT_LIST.md`, `/workspace`-independent: the earlier GBP BOM (`BOM_SOMA_arm_v2.csv`) lives off the Mac, so rebuild from `~/Vector/stages/BOM_SOMA_arm_v1.csv`, `cad/arm2b/BOM.md`, `cad/act2/BOM.md`, `pcb13/bom.csv`, `pcb12/` BOM and the sim/fea STATUS files.

## Tasks
1. **Stress sanity check (hand calcs).** The D2 FEA shows tiny stresses (housing 4 MPa, cradle 0.2–0.9 MPa, displacement ≈ 0.007 mm), which look optimistic because loads were spread by rigid spiders. Independently hand-calculate, with formulas and sources, for J2/J3 housing and J4 bracket: (a) M3 and larger bolt-hole bearing stress (force per bolt = M/(bolt PCD) etc. over d×t), (b) tension/shear at the weakest ligament near each bolt hole, (c) cycloidal pin contact (Hertz) and tooth bending for the 40:1 stage at the 3.5 N·m rated torque ×2, using the actual tooth/pin dimensions from `cad/act2/` params, against printed-material limits (cite; use 50% of datasheet for layer direction). Give SF for each. If any SF < 2, propose a concrete fix (thicker boss, metal insert/heat-set, larger pins, different material) and, if CAD-only and small, apply it on the copy and re-export. Be honest: state if the FEA was optimistic and by how much.
2. **Consolidated final BOM** `order/BOM_FINAL_GBP.csv` + `order/BOM_FINAL.md`: every component to build the whole arm (motors, ESCs, servos, bearings, fasteners incl. heat-set inserts and lengths, magnets if any, pins/rollers for the cycloidal, springs, filament, hardened nozzle if needed, wire/connectors/crimps, 12 V PSU, fuse and holder, e-stop switch, relay jumper/NC loop, CAN termination, USB, heatsinks, adhesives, etc.). Columns: item, spec, qty (+spares), UK supplier, product URL, unit £, line £, date checked, status (verified/[U]). Prefer UK stock; if an item is only from China/EU note landed cost and delivery time and import VAT. Check each URL actually loads. Resolve the open items: STS3250 real UK price and legitimate seller (the £15 eBay listing is suspicious: treat as [U] unless a genuine listing is found; also check Feetech/other UK resellers), the rack or gears if any are used, Tarot 4008 UK source, B-G431B-ESC1 UK stock (Farnell/Mouser UK/RS), AS5600 breakouts. Give two totals: verified-only, and with estimates. Never invent prices.
3. **PCB order pack** `order/PCB_ORDER.md`: re-run DRC on `pcb13` and paste the result; list gerber/drill/BOM/CPL files and which to upload to JLCPCB; recommended options (layers, thickness, finish, copper, quantity) and a real price quote if the JLCPCB site/calculator is reachable (else [U] + how to get it); LCSC/JLCPCB-assembly vs hand-solder decision with real part numbers and stock; UK shipping and import VAT estimate; and the relay K1 pad check against the Songle SRD-12VDC-SL-A datasheet (get the real datasheet; compare coil pads 1/2, COM 3, NO 5 against the footprint; report PASS or MISMATCH with the evidence). If MISMATCH, fix in a copy (`order/pcb13_fix/`) and re-run DRC.
4. **Assembly & bring-up guide** `order/BUILD_GUIDE.md`: ordered build steps (print order, post-processing, insert pressing, actuator assembly sequence incl. spring fitting and preload, servo horn alignment, wiring harness with a pin-by-pin table and wire gauges for the currents involved, PCB soldering order, first power-up procedure with current-limited supply, the e-stop NC loop jumper (J19 must be jumpered or motors never power), relay and MOTOR_EN checks, setting servo IDs and baud, flashing both firmwares (exact commands), homing, first moves) using the firmware docs in `docs/bringup.md`. Include a safety section (12 V high current, LiPo if used, hot nozzle, pinch points on the spring, blades). Include a one-page printable checklist.
