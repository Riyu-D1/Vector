Do not use the printed cycloidal actuators' rule as a limit here (that applies to J2/J3 only).

## Goal
Design (as CAD in code) an automatic tool changer so the arm can pick up, use and put down different end tools (e.g. the existing parallel gripper, a pen/pointer, a suction or hook tool, a camera/sensor tool) by itself at a docking rack on the table. "Automatic" = the arm's own motions lock/unlock the tool with NO extra actuator if possible (passive latch released by a J6 roll twist, a push-pin, or a docking-rack cam), so the 4-servo wrist does not grow.

## Tasks
1. Interface requirements: what must pass through the coupling: mechanical (tool weight, 0.5 kg payload moment, wrist torque loads, repeatable alignment/backlash target), and electrical (STS3215 half-duplex TTL bus: GND / +12 V / DATA for a powered gripper; plus a spare 2 signal lines for a sensor). Decide: does the gripper servo live in the arm (and the tool only carries passive fingers - "finger swap") or does each tool carry its own servo (powered tool - "tool swap")? Compare both with mass/CoG/joint-torque numbers using `gravity.py` and report the winner.
2. At least THREE concepts, each with a sketch/render and a trade-off table (mass, added length, parts count, repeatability, cost, print-ability, failure modes, how a user-in-the-loop-free dock works): (a) ball-detent bayonet/twist-lock released by a J6 roll twist against a rack tooth; (b) kinematic coupling (3 V-grooves + balls or 3 dowels) with spring-loaded latch and a push-to-release rack cam; (c) magnetic kinematic mount with pogo-pin power/data (state magnet pull-off force vs 0.5 kg payload, SF >= 2 with a mechanical lock if the magnet alone is not safe).
